# Privacy Policy — Avrae Inventory Exporter

**Effective date:** September 23, 2026

Avrae Inventory Exporter is a browser extension that converts inventory information from the D&D Beyond character sheet currently opened by the user into an Avrae `!invimport` command.

## Information the extension accesses

When the user opens the extension on a D&D Beyond character sheet, the extension accesses the D&D Beyond character information needed to create the inventory export. This can include the character name and identifier, inventory and equipment information, item quantities and weights, containers and their contents, attunement/equipment state, currency, and size or carrying-size information.

## How information is used

The information is used only to generate the Avrae `!invimport` command requested by the user and to display a small export summary in the extension popup.

## Storage and retention

The extension does not maintain a developer-operated database or server for character information. Character information is processed locally in the user's browser for the export operation. The generated command is copied to the user's clipboard only when the user selects the copy action.

## Sharing and sale of information

The developer does not sell character information. The extension does not send character information to a developer-operated analytics service, advertising service, or character-data server.

The extension communicates with D&D Beyond's character service in order to read the character the user has chosen to export. The user may then choose to paste the generated command into Discord/Avrae; that paste is an action performed by the user outside this extension.

## Permissions

The extension requests only browser permissions used for its export function: temporary access to the active character tab, execution of the packaged exporter in that tab, access to the D&D Beyond character-service host, and permission to write the generated command to the clipboard.

## Remote code

The extension does not download or execute remotely hosted extension code.

## Changes

If the extension's data practices materially change, this policy and the Chrome Web Store disclosures will be updated accordingly.

## Contact

For questions, support, or privacy concerns regarding Avrae Inventory Exporter, please open an issue in the project's GitHub repository.

## Independence

Avrae Inventory Exporter is an independent community tool and is not affiliated with, endorsed by, or sponsored by D&D Beyond, Wizards of the Coast, Discord, or Avrae.
